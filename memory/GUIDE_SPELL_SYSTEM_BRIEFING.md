# 📐 SPELL GENERATION FORMULA

## Two-Stage Pipeline

### Stage 1: PLANNER
```
Input: SpellSpec (user query, persona, feeling, time, tone, anchor object, setting)
Output: Plan (title, format, sources, practices, asset requirements)
```

The Planner:
1. Selects scenario based on `best_for` matching
2. Chooses format based on scenario's `linked_format`
3. Pulls practices from `linked_practices`
4. Generates text variation tokens for uniqueness
5. Creates asset plan for images

### Stage 2: SPELL WRITER
```
Input: Plan + SpellSpec + Persona Config
Output: Complete spell JSON with all sections
```

The Writer:
1. Follows `section_order` from format
2. Uses persona `voice` block for tone/phrases
3. Incorporates `micro_lore` for authenticity
4. Cites only from `allowed_sources`
5. Generates `tarot_card` quick-view

## Required Output Sections (V1.1 Contract)

Every spell MUST include:
- `why_this_works`: 4-7 paragraphs explaining materials and folklore
- `substitutions`: 3 items for accessibility
- `tiny_mistakes_to_avoid`: 3 safety/preparation notes
- `closing_and_aftercare`: Grounding and validation
